# ClassIsland 样式注入器

让 ClassIsland 再次伟大！自定义 ClassIsland 的显示行为和动画效果！

## 它能做什么

### 换皮肤
- **背景**：纯色、渐变色随便换，还能叠纹理，甚至还有**动态频谱**
- **背景图片**：放一张本地图片当壁纸，或者让一个文件夹里的图片自动轮播，甚至可以直接用正在播放的歌的专辑封面
- **边框和阴影**：加一圈边框、一个柔和的投影，提升精致感


### 跟着音乐变颜色
- 播放音乐时，主界面的背景、边框、阴影会自动变为专辑封面的配色
- **动态主题色**：把当前专辑的主色调应用到 ClassIsland 全局主题强调色

### 动起来
- **持续动画**：呼吸、浮动、波浪……让主界面轻轻动起来。

- **显示动画**：主界面出现 / 消失时，淡入淡出、缩放或滑入滑出

- **列表翻页动画**：自定义轮播容器、上课提醒横幅等列表的上翻切换动画

- **提醒特效**：收到提醒时有脉冲、弹跳、抖动、闪烁等强调动画，还有线性、放射、粒子、舞萌花火、爆炸、**屏幕涟漪**等各种 Ripple，甚至有一个覆盖整屏的**全屏流光效果**

- **即将上课倒计时**：快上课时，屏幕上会滑过箭头 `>>`、扩散光环、扫描线或**光带**，还可以叠加红色警告边框

  

- **点击特效**：点击主界面时产生轻微跳跃或软边扩散圆环反馈

### 虚假天气
- 向 ClassIsland 注入自定义天气数据，还能报告虚假**气象灾害预警**

### 可视化编辑器
- 像做 PPT 一样，在独立窗口里拖拽、旋转、调整圆角，所见即所得，改完一键应用到主界面

### 一键切换方案
- 把自己调好的整套效果保存成预设
- 配合 ClassIsland 的**自动化**，还能按时间、课程等条件自动切换方案


## 常见玩法

- **自习时更专注**：把不透明度调低，关掉花哨的 Ripple，只留简洁的边框和阴影
- **上课前有仪式感**：开启「即将上课样式」，用箭头或扫描线提醒自己
- **不同时段不同风格**：把几套方案存成预设，再用自动化按时间自动切换

## 宿主对照表（适配引擎）

插件访问 ClassIsland 内部结构所用的全部「点位」（控件名、类型名、反射成员、GUID 等）集中在一张对照表中。ClassIsland 大版本更新后若某些点位失效，插件会自动检测并在设置页顶部提示；你只需在「宿主对照表」区填写插件网站的索引地址、刷新列表，再下载与当前宿主版本匹配的对照表即可恢复工作，无需等待插件重新发布。

- **内置对照表**：随插件发布，适配插件发布时的宿主版本，零联网可用
- **联网对照表**：由插件作者（或社区）制作并挂在网站上，每个对照表标注了适配的 ClassIsland 版本区间、制作时间与作者
- **对照表文件**：`Defaults/contract-catalog.json`（对照表本体，可直接挂到网站）与 `Defaults/contract-index.sample.json`（网站索引文件样例，列出所有可用对照表）

## 卸载与清理

在插件设置页底部有「卸载与数据清理」，可以一键清除插件留下的所有配置数据；之后再在 ClassIsland 的插件管理里停用或移除插件即可。插件不会修改 ClassIsland 的任何文件，卸载后不留痕迹。

## 常见问题

- **装了之后没反应？** 先确认重启过 ClassIsland，再检查设置页里对应的开关是否打开了。
- **更新 ClassIsland 后特效不见了？** ClassIsland 更新后内部结构可能变化，插件会自动停用对应功能（静默降级，不报错不崩溃）。打开设置页顶部会提示哪些功能失效，可到「宿主对照表」区下载与当前宿主版本匹配的对照表立即恢复，无需等待插件更新。
- **跟随音乐变色不工作？** 确认系统是 Windows 10 1809 及以上，并且正在用支持系统媒体信息的播放器播放音乐（网易云、QQ 音乐等一般都可以）。

### 给爱折腾的你

插件还支持直接编写样式表（`.axaml` 文件）做更深度的定制，保存后会自动热重载，立刻生效。具体用法可以在设置页的「高级样式表」里查看说明。
