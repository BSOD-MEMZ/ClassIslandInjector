# ClassIsland 样式注入器

让 ClassIsland 的主界面变得更好看！不需要写代码、不需要碰任何文件——只要在设置里点一点、拖一拖，就能把主界面变成你想要的样子。

## 它能做什么

### 换皮肤
- **背景**：纯色、渐变色随便换，还能叠一层好看的纹理（网格、圆点、斜线、格子）
- **背景图片**：放一张本地图片当壁纸，或者让一个文件夹里的图片自动轮播，甚至可以直接用正在播放的歌的专辑封面
- **边框和阴影**：加一圈细边框、一个柔和的投影，精致感立刻提升

### 跟着音乐变颜色
- 播放音乐时，主界面的背景、边框、阴影会自动「学习」专辑封面的配色（和安卓 Material You 一样的取色算法）
- 暂停或停止播放时，颜色会平滑变回你自己设置的原始颜色

### 动起来
- **持续动画**：呼吸、浮动、波浪……让主界面轻轻动起来，幅度可调，不会吓到你
- **显示动画**：主界面出现 / 消失时，淡入淡出、缩放或滑入滑出
- **提醒特效**：收到提醒时，有脉冲、弹跳、抖动、闪烁等强调动画，还有各种炫酷的波纹扩散（Ripple），甚至有一个仿 maimai 的「花火」特效！
- **即将上课倒计时**：快上课时，屏幕上会滑过一排箭头 `>>`、扩散光环或扫描线，仪式感拉满（也可以选择不显示）

### 可视化编辑器
- 像做 PPT 一样，在独立窗口里拖拽、旋转、调整圆角，所见即所得，改完一键应用到主界面

### 一键切换方案
- 把自己调好的整套效果保存成预设，比如「自习模式」「上课模式」「周末模式」
- 配合 ClassIsland 的**自动化**，还能按时间、课程等条件自动切换方案

## 怎么安装

1. 等插件上架后，可以在 ClassIsland 的**插件商店**里直接搜索「样式注入器」安装；
2. 现在也可以在本项目的 [Releases](https://github.com/BSOD-MEMZ/ClassIslandInjector/releases) 下载 `ClassIslandInjector.cipx` 文件手动安装；
3. 安装后**重启 ClassIsland**，打开 **应用设置 → 样式注入器**，开始你的创作！

## 快速上手

1. 打开 **应用设置 → 样式注入器**
2. 顶部有**实时预览**开关（默认已开启），边调边看效果，不用反复点保存
3. 想更精细地调整？点「打开可视化编辑器」，像编辑幻灯片一样直接拖！
4. 调出满意的一套后，记得在「用户预设」里**保存成预设**，以后一键套用

> 小提示：想用「跟随音乐变色」「专辑封面壁纸」的话，需要 Windows 10 1809 及以上版本

## 常见玩法

- **自习时更专注**：把不透明度调低，关掉花哨的 Ripple，只留简洁的边框和阴影
- **上课前有仪式感**：开启「即将上课样式」，用箭头或扫描线提醒自己
- **不同时段不同风格**：把几套方案存成预设，再用自动化按时间自动切换

## 卸载与清理

在插件设置页底部有「卸载与数据清理」，可以一键清除插件留下的所有配置数据；之后再在 ClassIsland 的插件管理里停用或移除插件即可。插件不会修改 ClassIsland 的任何文件，卸载后不留痕迹。

## 常见问题

- **装了之后没反应？** 先确认重启过 ClassIsland，再检查设置页里对应的开关是否打开了。
- **更新 ClassIsland 后特效不见了？** 这是正常的保护机制——ClassIsland 更新后内部结构可能变化，插件会自动停止生效，不会报错也不会崩溃，等插件更新适配即可。
- **跟随音乐变色不工作？** 确认系统是 Windows 10 1809 及以上，并且正在用支持系统媒体信息的播放器播放音乐（网易云、QQ 音乐等一般都可以）。

### 给爱折腾的你

插件还支持直接编写样式表（`.axaml` 文件）做更深度的定制，保存后会自动热重载，立刻生效。具体用法可以在设置页的「高级样式表」里查看说明。
