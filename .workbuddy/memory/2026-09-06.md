## Issue #6 调查（MuttonIsHere：动态频谱存不上 + 遮罩变直角）

报告者的"1.10.4/1.10.5"实为 1.1.0.4/1.1.0.5（少打个点）。两个独立 bug，根因都已定位：

1. **动态频谱"无法保存"**：`WireTutorialExpander(_textureGroup, "expand-texture", after)` 的 after 回调在**没有教学运行时也会执行**（`HostTutorial.PushToNextSentenceByTag` 无 tutorial 时是 no-op，但 `after?.Invoke()` 无条件跑）。回调内容：强制打开底纹开关 + **若当前选中的是动态频谱则静默重置为网格线**（彩蛋逻辑，1.1.0.4 就有，所以两个版本都能复现）。重置触发 SelectionChanged → WireTextureBrush.Changed → TriggerLivePreview → 防抖后 SaveAndApply **把 Grid 落盘**。用户操作路径＝重新打开设置页手动展开「底纹纹理」组查看图案 → 当场被重置并保存 → 重进显示网格线，看起来像"保存坏了"。修复方向：after 回调仅在 `HostTutorial.IsTutorialRunning()` 时执行，或彩蛋重置不走会触发保存的控件路径。
   - 附带：若 AudioSpectrumCapture 构造失败，StartSpectrum 静默 return（行级宿主无 Child 无 Background）→ 频谱完全不显示，无任何提示。诊断日志已有（preview-debug.log，2s 节流）。
2. **遮罩（OverlayMask）圆角变 0（1.1.0.5 回归）**：1.1.0.5 把装饰循环的「保存/还原本地 CornerRadius」改成了 `borderControl.ClearValue(Border.CornerRadiusProperty)`（修"直角退化"问题的方案，依赖宿主样式绑定重新套用）。但宿主 Fluent/Classic 模板里 `OverlayMask` / `BackgroundBorderOverlayMask` 的 CornerRadius 是**模板 XAML 直接写的 attribute（= 本地值）**，不是样式 Setter → ClearValue 把它清掉后没有样式兜底 → 回落 0 → 遮罩变四边形。修复方向：ClearValue 只作用于 BackgroundBorder / 分体 line-background（样式驱动的），遮罩两类 Border 不碰；或只清除插件自己写过的本地值。
